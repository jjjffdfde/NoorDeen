Step-by-Step Android Installation Guide & Native Source Architecture

🔍 Technical Clarity on Android APK Installation:

On Android, installing a native .apk requires Dalvik executable bytecode (classes.dex), compiled binary Android XML (AndroidManifest.xml), and a cryptographic APK signing block. If an uncompiled archive is sideloaded, Android's PackageParser rejects it with: "There was a problem parsing the package."

To ensure 100% of Android users enjoy a flawless mobile experience without parse errors or sideloading security alerts, we recommend the Progressive Web App (PWA) above. It creates a verified Android WebAPK on your home screen in 2 seconds.

1

Choose Your Android Installation Track

• Regular Users (Recommended): Tap "Install Web App (PWA)" at the top of this page. Chrome/Edge will automatically register the offline WebAPK with zero sideloading warnings.
• Developers: Build the native Capacitor Android APK directly from the source code repository under android/.

2

Developer Native Build Specs (Capacitor & Gradle)

The native Android wrapper is included in the project under android/ with the following specifications:

  • Package ID: com.islamicknowledge.portal
  • Target SDK: Android 14 (API Level 34) • Min SDK: API Level 22 (Android 5.1+)
  • Activity: BridgeActivity (Capacitor Native WebView Bridge)
  • Build Command: npm run android:sync && cd android && ./gradlew assembleDebug

Optional developer package: Download islamic-portal-release.apk

3

Sideloading Permissions (If installing a native developer APK)

If sideloading a compiled .apk on Android:

  • When prompted with "Install unknown apps", open Settings and toggle on "Allow from this source".
  • Return to the installer and tap "Install".
4
