## 2. In-Depth Analysis of Flagged Content Areas

### 2.1 The Dynamic Pre-rendering Need in `duas.html` and `hadith.html`
* **Observation:** Both pages rely on client-side JS loops to populate `#duas-list-container` and `#hadiths-list-container` from `ISLAMIC_DATA` in `public/js/data.js`.
* **Impact:** Search engine bots that perform low-latency crawls receive an empty container (`<div></div>`) containing 0 supplications and 0 Hadiths.
* **Remediation Plan:** Pre-render all 32 Dua cards and 22 Hadith cards directly inside the server HTML templates. When JS initializes, it enhances the existing DOM rather than wiping and rebuilding it, ensuring 100% SEO visibility.

### 2.2 Rich Structured Schema Upgrades
* **Observation:** While all 25 pages currently possess valid `BreadcrumbList` schemas, high-intent instructional pages like `wudu-guide.html`, `salah-guide.html`, `janazah-guide.html`, and `eid-guide.html` can benefit from `HowTo` and `FAQPage` schemas according to Google Search Central guidelines.
* **Remediation Plan:** Add structured JSON-LD schemas representing the verified steps of Wudu, Salah, Janazah, and Eid prayers.
